# ローカルで起動する

起動手順はプロジェクトごとに違うので、**`AGENTS.md` の「ローカルでの起動」節に従う。**
このスキルは、その手順を安全に実行するための共通の決めごとだけを定める。

`AGENTS.md` に起動手順が書かれていなければ、推測で起動せず、ユーザーに手順を確認する。
確認できた手順は `AGENTS.md` に追記することを提案する。

## 1. 依存を確認する

`AGENTS.md` に書かれた前提（ツールのバージョン、インストール先、必要な設定ファイル）が
揃っているかを確認する。足りないものがあれば、何が足りないかを報告してから止まる。

認証が必要なもの（CLI のログイン、エディタのライセンス等）は、**ユーザーに依頼する**。
勝手に認証フローを進めない。

## 2. 起動する

- サーバーや長時間動くプロセスは**バックグラウンドで起動する**。前面で走らせるとセッションが固まる
- GUI アプリ（エディタなど）は起動するだけにして、終了させない
- ポートやロックファイルが既に使われていたら、既存のプロセスを止めてよいかユーザーに確認する

## 3. 動作を確認する

起動しただけで「動いた」と報告しない。`AGENTS.md` に書かれた確認項目を確かめる。
自分で確認できない部分（実機での操作感、見た目）は、ユーザーに確認手順を渡す。

うまく動かないときは、ログを読んでから報告する。

## 4. 止め方を伝える

バックグラウンドで動かしたプロセスの止め方をユーザーに伝える。
